# Airbnb NYC Tableau Dashboard

## Project Overview

This project is an interactive Tableau dashboard created to analyze Airbnb listings across New York City. The dashboard provides insights into Airbnb hosts, neighborhoods, room types, average prices, booking trends, reviews and top-performing hosts.

The main goal of this project was to build a visually clear and interactive dashboard that helps users understand Airbnb activity across different NYC neighborhood groups such as Manhattan, Brooklyn, Queens, Bronx and Staten Island.

## Dashboard Features

### 1. Total Bookings by Neighbourhood Group and Room Type

This stacked bar chart shows the total number of bookings across different neighbourhood groups and room types.

It helps compare Airbnb activity in:

- Manhattan
- Brooklyn
- Queens
- Bronx
- Staten Island

The room types included are:

- Entire home/apartment
- Private room
- Shared room

### 2. Neighbourhood Group Distribution

The donut chart shows the percentage distribution of neighbourhoods by neighbourhood group.

This helps identify which NYC boroughs have the highest share of Airbnb neighbourhood coverage.

### 3. Average Price by Neighbourhood

The horizontal bar chart displays the average price of Airbnb listings by neighbourhood.

This chart helps identify the most expensive neighbourhoods in the dataset.

### 4. Monthly Booking Trend

The dual-axis chart shows total bookings by month and neighbourhood group.

It helps identify seasonal booking patterns and understand which months have higher Airbnb activity.

### 5. Average Reviews per Month by Room Type and Neighbourhood Group

The highlight table compares average reviews per month across different room types and neighbourhood groups.

This helps understand which room types receive more frequent reviews in each borough.

### 6. Average Price by Neighbourhood Group

The treemap shows the average Airbnb price by neighbourhood group.

This visualization makes it easy to compare pricing across NYC boroughs.

### 7. Map View

The map visualization displays Airbnb neighbourhood locations geographically across New York City.

It helps understand the spatial distribution of listings and pricing patterns.

### 8. Total Reviews by Year

The bar chart shows the total number of reviews by year.

This helps analyze how Airbnb review activity changed over time.

### 9. Top 10 Hosts by Total Reviews

This table shows the top hosts based on total number of reviews.

It includes:

- Host name
- Neighbourhood group
- Neighbourhood
- Average price
- Total reviews

## Key Insights

- Manhattan and Brooklyn have the highest Airbnb activity compared to other neighbourhood groups.
- Manhattan has the highest average price among all neighbourhood groups.
- Entire home/apartment and private room listings make up most of the Airbnb bookings.
- Booking activity is highest during the summer months, especially around June.
- Total reviews increased significantly over the years, with the highest review count appearing in 2019.
- Some neighbourhoods, such as Fort Wadsworth, show very high average prices compared to others.
- Bronx and Staten Island have lower Airbnb activity compared to Manhattan, Brooklyn and Queens.
- Top hosts are mainly located in Manhattan, Brooklyn and Queens.
- Manhattan and Brooklyn together represent a large portion of Airbnb neighbourhood distribution in NYC.
- Shared rooms are less common compared to private rooms and entire home/apartment listings.

## Project Workflow

1. Loaded the Airbnb NYC dataset.
2. Explored the dataset in Excel.
3. Cleaned and prepared the data for Tableau.
4. Created calculated fields for KPI cards.
5. Built individual Tableau worksheets for each visualization.
6. Created charts including bar charts, treemap, donut chart, map, highlight table and dual-axis chart.
7. Added filters for neighbourhood group and room type.
8. Designed the final dashboard layout.
9. Added interactivity between filters and worksheets.
10. Published the final dashboard on Tableau Public.
